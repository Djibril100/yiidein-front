# Yiidein – Frontend

Application frontend du projet **Yiidein**, une plateforme de gestion de rendez-vous (administratifs, médicaux, services publics), développée dans un cadre collaboratif.

## Objectif
Fournir une interface web simple permettant :
- la consultation des services disponibles,
- la prise de rendez-vous,
- la gestion des clients, prestataires et rendez-vous,
- l’interaction avec l’API backend Yiidein.

## Technologies
- Angular
- TypeScript
- HTML / CSS
- API REST (consommation du backend Spring Boot)

## Fonctionnalités principales
- Interface utilisateur pour la prise et le suivi des rendez-vous
- Connexion avec le backend via HTTP
- Affichage dynamique des données (services, prestataires, clients)
- Architecture frontend claire et modulaire

## Architecture
- Composants Angular
- Services Angular pour les appels API
- Séparation logique entre vues, services et modèles

## Contexte
Projet développé entre amis guinéens avec pour objectif de faciliter la prise de rendez-vous en Guinée, mais conçu de manière générique pour être adaptable à d’autres domaines.
